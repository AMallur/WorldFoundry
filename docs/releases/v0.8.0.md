# WorldFoundry 0.8.0 release notes

This release adds **experimental local** reality reconstruction and verification utilities to the Python SDK.

## New capabilities

- Stateful `reality` workflow template: reviewed rules, guards, atomic multi-effect state updates and reference-case grading.
- `ReferenceCase`, `propose_actions`, `verify_reference_cases`, and `cases_to_scenarios` for evidence-based rule proposals and state/response comparisons.
- `inspect_openapi` for endpoint inventory without guessing hidden API behavior.
- Offline OpenTelemetry span, Debezium CDC row and directly-follows event import; optional PM4Py integration.
- Optional MCP stdio bridge for one local episode (`worldfoundry[mcp]`).
- Optional independent Meta ARE command-line runner (`MetaARERunner`).
- Automated tests and updated installation/documentation.

## Installation

```bash
python -m pip install --upgrade worldfoundry==0.8.0
python -m pip install "worldfoundry[mcp]==0.8.0"
python -m pip install "worldfoundry[process]==0.8.0"
```

## Status

**Alpha; not production-certified.** Inference from before/after cases is narrow and must be reviewed; simulation agreement on recorded test cases does not guarantee equality with real enterprise behavior. No live vendor integrations or secrets are bundled. Supabase hosted execution remains separate from the local reality engine. The Meta ARE runner invokes the separate installed ARE binary; world state is not shared.

See [Reality SDK guide](../reality-engine.md) and [repository](https://github.com/AMallur/WorldFoundry) for details.
